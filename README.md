# IPOFlow · IPO 智览（A股首发上市全景看板）

零成本打造的 A股IPO 首发上市数据聚合与实时查询看板，采用 **Google Material Design 3 蓝白极简风**，实现 **0 元服务器费用、0 元商业接口费用、每日自动更新**。

- **全功能公网地址（推荐，含方案 B 实时详情）**：https://ipoflow.pages.dev
- **纯静态备份地址（GitHub Pages）**：https://gaohuatj.github.io/ipoflow/
- **GitHub 仓库**：https://github.com/GaoHuaTJ/ipoflow

### Day 2（2026-11-22）：阶段二全面上线 + 辅导备案深度重构 + 全站体验升级

#### 1. 阶段二全模块正式上线
- **上市委审议（583 条）& 发行动态（666 条）**：
  - 接入全面注册制以来上市委会议审议记录与过会率 KPI 看板；

- **新三板挂牌（1,007 条）& 全景图总所归并口径**：
  - 官方直连全国股转系统（`neeq.com.cn`，自动维护 `C3VK` Cookie）采集 2023 年至今新挂牌企业；

#### 2. 全市场「辅导备案」深度重构与 PDF 自动解析
- **全量修复 + 增量持久化 + 报告分片**：
  - 官方直连中国证监会辅导公示平台（`http://eid.csrc.gov.cn/csrcfd/`），修复无展开符号 `>` 的单份报告新备案行漏抓 Bug，全市场覆盖增至 **1,194 家**（覆盖全国 36 个派出机构，`贵州证监局` 等全部纳入）；
  - 升级 `scripts/fetch_phase2_w2.py` 为先读存量再增量合并模式，确保历史企业滚出官网 60 页滚动窗口后仍长期留存；
  - 收集每家企业的完整历史报告列表（共 **13,040 份**）并按公司名哈希拆分为 `16` 个分片（`data/tutoring_reports/{0..f}.json`），主数据保持 **2.18 MB** 极速加载，详情页按需拉取单个轻量分片（最大 `372 KB`）。
- **`pypdf` + `macOS Vision OCR` 双引擎报告解析 & 交叉补全**：
  - 并发解析重点与最新 250 家企业《辅导备案报告》/《进展报告》（前 100 家律所填充 **96%**、会所填充 **95%**，全库已补全 **453 家**）；
  - 新增原生零第三方依赖的 `scripts/pdf_ocr.swift`（基于 macOS `PDFKit + Vision` 按表格行坐标分桶），攻克纯图片扫描件 PDF 提取难题，同时在 `server.py` 新增 `/api/tutoring-detail` 支持本地实时解析兜底；
  - 交叉比对 `ipo_data.json`（标记 `108` 家已受理企业及板块/中介）与 `neeq_data.json`（挂牌情况校验）。
- **概览页与详情页全新改版**：
  - **概览页**：升级为「场所 / 阶段（含 `辅导备案·辅导中期·辅导验收 | 未受理·已受理·辅导终止`）/ 证监局（Top 6 + `展开更多` 面板）」三行筛选与 10 列表格，支持 `更新日期` / `备案日期` 升降序排序与醒目的暖橙色 `尚未受理` 标签；
  - **详情页（`#view-tutoring-detail`）**：新增吸顶企业横幅、3 节点进度条（含进行中前半绿后半灰渐变连线）、`（一）基本信息`（成立时间、注册资本、注册地址、控股股东、行业分类、三方中介、前次申报、挂牌情况）与 `（二）信息披露`（三大类报告分组表格直达官方 PDF）。

#### 3. 全站口径统一、分页升级、移动端适配与更名 `ipoflow`

## 三、本地开发与常用命令

```bash
# 1. 启动本地静态托管 + 实时详情代理服务（http://127.0.0.1:8080，含交易所直连与 /api/tutoring-detail）
python3 server.py

# 2. 更新全部公开数据（辅导备案 PDF 解析需安装 pypdf）
python3 -m pip install pypdf
python3 scripts/fetch_ipo_data.py
python3 scripts/fetch_phase2_data.py
python3 scripts/fetch_phase2_w2.py

# 3. 仅更新辅导备案并对扫描件使用 macOS Vision OCR 补全（示例补全 300 家）
python3 scripts/fetch_phase2_w2.py --only-tutoring --reparse-scanned --parse-pdfs 300

# 4. 提交并推送上线
git add .
git commit -m "feat: 描述你的修改"
git push origin main
```
